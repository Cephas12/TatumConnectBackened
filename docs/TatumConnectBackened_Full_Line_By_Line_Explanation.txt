File: Services/AuthService.cs
(Note: This file is longer; explanations reference logical blocks and the most relevant lines. Line numbers correspond to file content.)
1-14: using and namespace imports - bring in options, configuration, DTOs, entities and repositories.

Constructor and Fields:
- Fields declared for repositories, JwtService, settings, notification service, email settings, configuration. These store injected dependencies.
- The constructor assigns injected types to private fields. IOptions<T> is used to obtain configured options.

RegisterAsync:
- Trims and normalizes email and phone input; validates presence.
- Checks for existing user by email using IUserRepository.GetByEmailAsync.
- If existing and not verified, returns failure indicating registration pending; if existing and verified, returns failure stating email exists.
- Generates OTP via GenerateOtp (random 6-digit number) and builds a new User entity with hashed password (HashPassword uses SHA256), sets role to Customer, sets registration OTP and expiry.
- Adds user via repository and calls SavedChangesAsync to persist.
- Calls SendRegistrationOtpAsync which composes an email message and calls NotificationService.SendEmailAsync.
- Returns success ApiResponse with mapped UserDto (MapToDto).

Other helpers in file:
- GenerateOtp: uses RandomNumberGenerator.GetInt32 to produce cryptographically secure random 6-digit number.
- SendRegistrationOtpAsync: formats a multi-line string (interpolated raw string) and delegates to notification service.
- HashPassword: SHA256 -> base64 encoded hash.
- VerifyPassword: compares hashed candidate password with stored hash.
- MapToDto: maps User entity fields to UserDto.

LoginAsync and verification flows:
- LoginAsync finds user by email, checks registration verified/active, compares password hash, uses JwtService.GenerateAccessToken to create token, and returns LoginResponseDto containing token and user data. (Details are inside file.)

Notes:
- Uses SHA256 for password hashing; this is not recommended for password storage in production (prefer Argon2, bcrypt, or PBKDF2 with salt).
- Many error conditions return ApiResponse.Fail with ApiError details used by controllers to send proper HTTP status codes.
